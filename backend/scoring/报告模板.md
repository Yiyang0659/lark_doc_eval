## 📝 报告填写指南

### 1. 基本信息填写

- **文档标题**：直接从文档获取
- **文档链接**：填写完整的飞书文档链接
- **评估时间**：填写评估日期，格式：YYYY年M月
- **文档类型**：根据文档内容判断，常见类型：
  - 技术方案
  - 实践总结
  - 工具介绍
  - 操作手册
  - 最佳实践
  - 其他

### 2. 综合评分计算

```
综合得分 = 实际价值 × 0.30 + 可复用性 × 0.25 + 创新性 × 0.25 + 方法沉淀 × 0.20
```

### 3. 等级判断

根据综合得分确定等级：
- 18-20分 → 🌟 卓越
- 15-17分 → ✅ 优秀
- 12-14分 → 🆗 良好
- 8-11分 → ⚠️ 一般
- 4-7分 → ❌ 较差

### 4. 各维度分析

每个维度的分析应包含：
- 核心发现（2-3条）
- 具体评估（子项评估表）
- 佐证材料或创新亮点

### 5. 总体评价

- 核心优势：3-5条
- 改进建议：3-5条，每条需说明针对哪个维度
- 推荐程度：明确是否推荐，说明理由和适用人群

### 6. 评分依据摘要

总结3-5条关键发现，作为评分的主要依据
